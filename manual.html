1. 화면 구성

왼쪽 사이드바에는 보기 전환 메뉴, 오늘의 루틴&알람, 연결된 GitHub 프로젝트, 태그 목록이 있습니다.

오른쪽 메인 화면 상단 헤더에는 오늘 날짜와 누적 몰입 시간, 뷰 탭, 다크모드 토글이 있고 우하단에는 ＋ 할 일 추가 버튼(FAB)이 항상 떠 있습니다.

2. 세 가지 보기

  • 먼슬리 — 한 달을 한눈에. 날짜 칸 안의 점은 그날의 태그 색을 의미합니다. ◀ ▶ 로 월 이동, 오늘 버튼으로 즉시 복귀.
  • 날짜 클릭 → 상세 보기 — 아무 날짜나 클릭하면 그날의 일정과 루틴이 펼쳐집니다(드릴다운). 먼슬리로로 돌아갑니다.
  • 위클리 — 시간대별 가로 그리드로 하루 흐름을 확인합니다.
  • 10분 트래커 — 하루를 10분 단위 칸으로 쪼갠 뷰. 자세한 사용법은 4장 참고.

3. 루틴 & 알람

사이드바의 루틴 카드는 색으로 종류를 구분합니다 — 이 색 규칙은 앱 전체에서 절대 바뀌지 않습니다:

아이콘 색의미
● 코럴 핑크약 복용 등 매일 챙겨야 하는 알람
● 라벤더Claude 코워크가 자동으로 모아준 AI 추천 루틴 (AI 배지 표시)
● 민트스트레칭 등 일반 습관 — 완료하면 별을 획득한 느낌으로 처리
색만 보고도 "이건 내가 챙긴 건지, AI가 모아준 건지" 바로 구분되도록 설계했습니다.

4. 10분 타임 트래커

이 앱의 핵심 기능입니다. 하루(08:00~22:00)를 10분짜리 칸으로 쪼갠 그리드가 나타납니다.

  • 칸을 클릭할 때마다 태그 색이 순서대로 순환합니다 (업무 → 운동 → 딥워크 → 학습 → 비우기).
  • 상단 통계 카드에 오늘 기록한 블록 수와 누적 몰입 시간이 실시간으로 갱신됩니다.
  • 목표는 "얼마나 계획대로 했나"가 아니라 "실제로 몇 분 몰입했는지"를 눈으로 확인하는 것 — ADHD 특성상 체감 시간과 실제 시간의 괴리가 크기 때문입니다.

5. GitHub 자동화 & 경험치 시스템

scripts/track_progress.py가 매일 밤 22:00에 launchd로 자동 실행되어 GitHub 커밋과 로컬 폴더 활동을 감지합니다.

카테고리감지 대상XP
코딩테스트algo-study-notebooks, LeetCode, coding-test 리포 커밋커밋당 +10
CS/학습llm 관련 실습 리포 커밋기록만
프로젝트그 외 앱/프로젝트 리포 커밋기록만
이력서 작성job_prep 폴더 파일 변경기록만
LEVEL = floor(XP / 100) + 1　·　100XP마다 레벨업

코딩테스트 문제를 매일 풀어 커밋하면 스트릭(연속일)이 올라가고, 하루라도 거르면 1로 리셋됩니다 — 백준 스트릭과 동일한 규칙.

# 수동 실행
python3 scripts/track_progress.py

# 처음부터 다시 시작하고 싶을 때 (과거 기록 소급 없이)
python3 scripts/track_progress.py --reset
최근 30일 기준 카테고리별 균형(%)도 함께 출력됩니다 — 코딩테스트만 파고 CS/프로젝트/이력서를 놓치고 있진 않은지 확인용.

6. 공략 팁

  • 화면 오른쪽 상단 다크모드 버튼으로 야간용 팔레트 전환.
